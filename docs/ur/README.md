## ویب سائٹ ایک نظر میں

- **عوامی حصہ:** مصنوعات، خدمات، شرحیں، مالی رپورٹیں، برانچوں کی فہرست، خبریں، نوکریاں، ڈاؤن لوڈز، لون کیلکولیٹر، رابطہ فارم۔
- **ایڈمن پینل:** ویب سائٹ کا ہر مواد یہاں سے بدلا جاتا ہے۔ اس کے لیے `/login` پر جائیں۔
- **عوامی API:** دوسرے سسٹمز یا ایپس کے لیے برانچوں، رابطے، شرحوں، خبروں اور نوکریوں کی معلومات (دیکھیں [docs/api.md](../api.md))۔

## چند بنیادی اصول

1. ہر شخص کا اپنا اکاؤنٹ ہو۔ پاس ورڈ کسی کے ساتھ شیئر نہ کریں۔
2. صرف وہی اجازتیں دیں جن کی ضرورت ہو۔ "سپر ایڈمن" بہت کم لوگوں کے پاس ہو۔
3. کوئی چیز حذف کرنے سے پہلے سوچ لیں، حذف شدہ مواد واپس نہیں آتا۔
4. تبدیلی کے بعد عوامی صفحے پر جا کر خود دیکھ لیں کہ صحیح نظر آ رہا ہے۔
