# عام مسائل اور ان کا حل

[← فہرست پر واپس](README.md)

| مسئلہ | وجہ | حل |
|---|---|---|
| لاگ اِن نہیں ہو رہا | غلط پاس ورڈ یا اکاؤنٹ نہیں | بہت بار غلط کوشش پر کچھ دیر رکنا پڑتا ہے۔ سپر ایڈمن سے پاس ورڈ بدلوائیں۔ آئی ٹی: `php artisan bank:create-admin ای-میل` پاس ورڈ دوبارہ بنا دیتا ہے |
| ایڈمن میں "403" یا بٹن غائب | اس کام کی اجازت نہیں | User Management ← Roles میں اجازت شامل کروائیں |
| تبدیلی کے بعد عوامی صفحہ نہیں بدلا | براؤزر یا سرور کیش | Ctrl+F5 دبائیں۔ مینیو ہو تو **Clear Cache**۔ آئی ٹی: `.env` بدلی ہو تو `php artisan config:cache` |
| تصویر کی جگہ سادہ ڈیفالٹ تصویر | فائل اپ لوڈ نہیں ہوئی یا `storage:link` نہیں | تصویر دوبارہ اپ لوڈ کریں۔ آئی ٹی: `php artisan storage:link` |
| ڈاؤن لوڈ کا لنک "404" | فائل موجود نہیں، یا آئٹم Inactive، یا نوکری بند | آئٹم Active کریں اور فائل دوبارہ لگائیں |
| خبر ویب سائٹ پر نظر نہیں آ رہی | Published بند ہے یا تاریخ آنے والی ہے | Is published آن کریں اور تاریخ آج یا پہلے کی رکھیں |
| نوکری فہرست میں نہیں | Active بند یا آخری تاریخ گزر گئی | Active کریں اور Closing date درست کریں |
| رابطہ فارم کی ای میل نہیں آتی | `MAIL_*` درست نہیں | پیغام پھر بھی Contact Messages میں موجود ہوتا ہے۔ آئی ٹی `MAIL_HOST` وغیرہ ٹھیک کرے |
| سب کو "Too many requests" | پراکسی کے پیچھے `TRUSTED_PROXIES` نہیں | `.env` میں `TRUSTED_PROXIES=*` لگائیں، پھر `php artisan config:cache` |
| سفید صفحہ / "Vite manifest" | فرنٹ اینڈ بلڈ نہیں | `npm ci && npm run build` |
| ڈیپلائے `bank:check` پر رک گیا | `.env` غیر محفوظ ہے | پیغام پڑھیں، مثلاً `APP_DEBUG=false` کریں اور دوبارہ چلائیں |
| "The cookie name cannot be empty" | `.env` میں خالی `SESSION_COOKIE=` | وہ سطر حذف کریں |
| نقشہ/قریب ترین برانچ غلط | برانچ کے عرض بلد/طول بلد درست نہیں | Branches میں مقام درست کریں (ڈیش بورڈ پر "بغیر مقام والی برانچیں" گنتی دکھاتا ہے) |

## مزید مدد

1. مسئلے کا اسکرین شاٹ اور وقت نوٹ کریں۔
2. آئی ٹی کو بتائیں؛ سرور پر `storage/logs/laravel.log` میں غلطی کی تفصیل ملتی ہے۔
3. غلطی کی بات رپورٹ کرتے وقت پاس ورڈ یا `.env` کی معلومات ہرگز نہ بھیجیں۔
